# Proposal

需求章节：1.1 AI论文与学术稿件检测。负责人：① 高佳楠。状态：业务待实现。

## Why

为AI文本检测提供独立的“AI论文与学术稿件检测”业务能力，当前只完成场景导航与空白页面。

## What Changes

- 论文提交与内容选择：支持粘贴论文正文或上传文档。文档上传后，通过文档解析功能精准切分章节与段落，再选择整篇论文或指定章节进行检测。
- AI生成风险识别：分析论文中的AI生成线索，展示整篇及各章节的风险情况。
- 可疑段落标注：在原文中标出疑似AI生成的段落，便于作者、导师和编辑找到需要核查的内容。
- 引用与参考文献处理：区分正文、引用和参考文献，允许将参考文献等内容排除后再检测。
- 检测报告：汇总论文风险、可疑段落与检测范围，支持在线查看、保存和导出。

- 当前框架页面仍为空；负责人可按已分配场景独立开发，本轮只同步文档。
- 非目标：其他场景业务、成员邀请、生产部署；不在前端存储密钥。
- 完整需求见[需求摘录](../../references/AI检测平台_需求摘录.md)第 3 页。

## Capabilities

### New Capabilities

- `text-academic`：AI论文与学术稿件检测。

### Modified Capabilities

无。

## Impact

场景 `#/text/academic`，业务接口 `POST /api/v1/text/academic`。复用[公共约定](../define-shared-foundation/specs/shared-foundation/spec.md)，具体请求和结果类型在实现时与公共部分对齐。

职责与交接：仅负责1.1论文场景。新闻、三审三校、网文与重复水稿归②；与②统一文本结果和原文位置格式，不把论文处理流程作为其他文本场景的前置条件。
