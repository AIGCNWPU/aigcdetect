# Proposal

需求章节：3.3 售后与退货AI视频凭证检测。工作包负责人：④ 闭耀松。

职责边界见[团队分工](../../../docs/TEAM_DEVELOPMENT.md)，公共行为见[公共约定](../define-shared-foundation/specs/shared-foundation/spec.md)。

## Why

售后凭证需要将来源分析与商品资料核对关联到同一份上传材料，为人工审核提供可复查的依据。

## What Changes

- 实现Native-Scale 视频片段来源分析、MIRROR 关键画面与中心细节核对、固定多帧综合判定、DeepSeek 商品资料核对、原视频时间定位和当前汇总。
- 来源分数与补充细节分数分别呈现，提供画面优先与互补复核两种建议；某项失败保留有效结果并明确部分完成。
- 提供材料校验、提交后页签跳转、独立任务、取消和失败重试。
- 会话绑定原文件与资料，修改或关闭后不接纳旧结果。
- 保留一键演示输入，实际结论由服务返回；产品只展示功能名。
- 来源复核触发后自动使用 FLAME 检查最多8个完整原视频画面，展示带时间戳的候选掩码与原图对照；定位失败保留来源结果。
- 本次分析汇总支持直接导出 PDF，沿用图片报告的品牌、图表及分页组件，包含当前视频资料、独立来源分数、采样位置、关键帧原图与实际标记、商品核对及失败状态。

本工作包不提供历史案件回看、自动退款裁决或生产多用户权限。模型分数和候选位置仅用于人工复核。

## Capabilities

### New Capabilities

- `video-aftersales`：退换货视频凭证分析。

### Modified Capabilities

无。

## Impact

涉及本场景页面、后端接口、模型服务封装、构建登记、相关测试和说明。HTTP入口、公共样式与OpenAPI变更集中覆盖已实现售后场景，其余场景保持原状态。

当前流程：上传视频 → 当前会话 → 视频片段来源 / 关键画面与多帧综合核验 / 商品核对 → 来源触发后关键帧局部定位 → 原视频回看与当前汇总。

运行与验证见 [设计、部署与验证](design.md)。公共集成、完整业务验收及正式规格归档保持未完成。
