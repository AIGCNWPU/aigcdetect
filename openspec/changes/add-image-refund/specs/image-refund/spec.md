# Spec Delta

## Purpose

为售后审核人员提供案件资料和多张图片凭证的整理入口，能够在当前页面填写资料、检查文件、预览及移除图片，并为后续后端接入留出提交位置。本轮不实施真实检测，也不将页面内材料误称为已保存到服务器。

## ADDED Requirements

### Requirement: 案件资料填写
前端 SHALL 提供案件编号、商品名称、款式、商品资料和问题描述输入，保留当前页面的编辑内容；明确刷新或离开页面不保证恢复。

#### Scenario: 填写与提交校验
- **WHEN** 用户编辑资料后添加或移除图片
- **THEN** 已填写内容保持不变；尝试提交时校验案件编号、商品名称和问题描述非空，款式与补充商品资料可选

### Requirement: 图片凭证添加与预览
前端 SHALL 支持选择或拖拽JPG、PNG、WebP图片，单张不超过5 MiB、总数不超过10张；校验可读性，展示缩略图和可关闭的大图预览，并可逐张移除。

#### Scenario: 多图预览与移除
- **WHEN** 用户添加多张有效图片，打开其中一张并随后移除
- **THEN** 列表展示每张缩略图、文件名和大小，大图可用关闭按钮或Escape退出；移除仅影响选中图片，数量同步更新

#### Scenario: 混合无效文件与数量限制
- **WHEN** 批次含不支持、空文件、超限或损坏图片，或有效图片总数将超过10张
- **THEN** 逐项显示拒绝原因，保留能加入的有效图片，总数不超过10；空文件选择不改变当前材料

#### Scenario: 当前页面数据与安全呈现
- **WHEN** 用户预览文件名含特殊字符的图片，或刷新页面
- **THEN** 文件名按文本展示，不执行其中内容；刷新不声称恢复或已保存材料，不产生自动上传

### Requirement: 提交入口与后端边界
前端 MUST 将资料和已校验图片封装成独立的提交快照，通过可替换适配入口调用；未配置后端时明确提示，不发送材料、不伪造保存或检测成功。公共协议仍引用[公共约定](../../../define-shared-foundation/specs/shared-foundation/spec.md)。

#### Scenario: 后端尚未接入
- **WHEN** 用户填入必填资料、加入至少一张图片并点击提交材料
- **THEN** 默认提示后端未接入，资料和图片仍保留在当前页面，不显示风险结论或成功上传

#### Scenario: 适配调用失败或重复提交
- **WHEN** 未来接入的适配器正在处理或返回失败
- **THEN** 处理期间防止重复提交和编辑当前材料，失败后恢复操作并保留输入；只有明确确认接收的返回才显示材料已接收，不代表检测完成

#### Scenario: 提交等待期间离开页面
- **WHEN** 用户在提交尚未完成时点击导航离开当前页面
- **THEN** 页面允许离开，向适配器发送取消信号并释放提交锁和预览资源；即使适配器未响应取消，也结束本次前端等待，忽略迟到回执，不影响再次进入后的提交
