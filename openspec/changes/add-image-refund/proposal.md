# Proposal

需求章节：2.2 仅退款与售后AI凭证检测。负责人：④ 闭耀松。
负责人工作包沿用现有变更。第一轮已交付案件资料填写＋图片凭证添加与预览；用户于2026-10-21确认第二轮：02 AI生成凭证检测与03 局部篡改检测的前端交互及结果展示，后端接口继续预留。

## Why

先让客服能整理案件资料与图片凭证，形成独立可验收的小功能；检测与风险复核后续逐步实现。

## What Changes

- 填写案件编号、商品名称、款式、商品资料和问题描述。
- 选择或拖拽多张图片，显示缩略图、点击查看大图、移除图片。
- 校验格式、大小和可读性，逐项说明错误；有效文件不被同批无效文件阻断。
- 预留材料提交适配入口；默认后端未接入，不发送文件、不生成检测结果。
- 提交等待期间允许离开页面；未完成的提交响应取消并释放锁，迟到回执不影响新页面。
- 新增两类检测选择、逐图处理状态和失败重试；仅渲染适配器实际返回并校验过的结果。
- 分开展示整图AI风险与局部篡改风险、覆盖范围和说明；局部区域可在原图上定位、选择并查看类型与详情。

非目标：真实上传服务与检测算法、商品描述核对、案件风险汇总、正式页面演示数据、草稿持久化、历史版本、3.3。本次内容只在当前页面保留，刷新或离开页面不保证恢复。

## Capabilities

### New Capabilities

- `image-refund`：案件资料与图片整理，以及AI来源与局部篡改检测前端。

### Modified Capabilities

无。

## Impact

修改refund页面及独立客户端模块、限定场景样式、打包清单、相关测试及接入文档。服务端和10个501接口保持现状；共享文件变更在PR列明。

公共字段、权限及状态引用[公共约定](../define-shared-foundation/specs/shared-foundation/spec.md)。前端提交对象只是适配输入，不发布新的公共协议。自检通过后将代码与四份OpenSpec一起更新PR #1，不归档整个2.2工作包。

需求依据：[需求摘录](../../references/AI检测平台_需求摘录.md)第7页及用户确认的小功能范围。真实检测服务、商品核对和案件风险汇总继续保留为后续工作。
