# Proposal

需求章节：2.2 仅退款与售后AI凭证检测。负责人：④ 闭耀松。状态：业务待实现。

## Why

为AI图片检测提供独立的“仅退款与售后AI凭证检测”业务能力，当前只完成场景导航与空白页面。

## What Changes

- 售后凭证整理：按售后案件集中上传图片，并填写商品信息和用户的问题描述。
- AI生成凭证检测：检查用户上传的破损照、污损照等凭证是否存在AI生成风险。
- 局部篡改检测：检查破损、污渍等局部区域是否被添加、替换、拼接或消除，标出可疑区域，与整图AI生成风险分别展示。
- 商品与描述核对：辅助核对凭证中的商品外观、款式及问题现象，与商品资料和用户描述是否一致。
- 案件风险汇总：汇总每张凭证的AI生成风险、局部篡改区域及待核对问题，便于客服审核、补证和申诉复查。

- 当前框架页面仍为空；负责人可按已分配场景独立开发，本轮只同步文档。
- 非目标：其他场景业务、成员邀请、生产部署；不在前端存储密钥。
- 完整需求见[需求摘录](../../references/AI检测平台_需求摘录.md)第 7 页。
