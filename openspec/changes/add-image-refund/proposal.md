# Proposal

2026-10-22缺陷修复范围：按用户“检查昨天工作并完善”的要求，修复编辑资料后旧提交回执未失效、提交中切换页签后结果提示不可见、键盘重试与取消时焦点丢失。沿用原工作包和分支，保持既有业务范围及后端待接入边界。

需求章节：2.2 仅退款与售后AI凭证检测。负责人：④ 闭耀松。
负责人工作包沿用现有变更。第一轮已交付案件资料填写＋图片凭证添加与预览；用户于2026-10-21确认第二轮：02 AI生成凭证检测与03 局部篡改检测的前端交互及结果展示，后端接口继续预留。

用户已确认第三轮：补齐04 商品与描述核对、05 案件风险汇总前端，保留真实后端待接入边界。

第四轮拟调整页面组织：用户于2026-10-21确认本轮短规格，按三个页签与紧凑汇总范围实施。负责人及需求章节沿用上述归属。

## Why

前三轮已交付五项核心前端能力。当前材料、检测详情和逐图汇总纵向堆叠，增加图片后滚动距离较长；第四轮通过页签和紧凑汇总，减少客服在资料、原图与问题之间往返滚动。

## What Changes

- 填写案件编号、商品名称、款式、商品资料和问题描述。
- 选择或拖拽多张图片，显示缩略图、点击查看大图、移除图片。
- 校验格式、大小和可读性，逐项说明错误；有效文件不被同批无效文件阻断。
- 预留材料提交适配入口；默认后端未接入，不发送文件、不生成检测结果。
- 提交等待期间允许离开页面；未完成的提交响应取消并释放锁，迟到回执不影响新页面。
- 新增两类检测选择、逐图处理状态和失败重试；仅渲染适配器实际返回并校验过的结果。
- 分开展示整图AI风险与局部篡改风险、覆盖范围和说明；局部区域可在原图上定位、选择并查看类型与详情。
- 对照商品外观、款式与问题现象，展示原资料、图片观察、一致/不一致/无法判断及依据，支持单项失败重试。
- 按案件汇总每张凭证的AI风险、篡改区域和待核对问题，可筛选并返回对应图片/区域；未检测、失败与部分覆盖明确区分。

第四轮范围：
- 在同一案件工作区提供“案件与凭证 / 检测与核对 / 案件汇总”三个可自由切换的页签，每次只展示当前面板。
- 页签上方持续显示案件编号、图片数量与检测进度；内部切换保持资料、图片、选择和在途任务。
- 检测页桌面按图片列表、原图、结果组织，结果区可切换“风险检测 / 商品核对”；窄屏展示当前图片，避免三栏挤压。
- 汇总默认显示紧凑清单，保留逐图状态、AI风险、区域数量、待核对项；说明与证据按需展开，点击定位切到对应检测详情。
- 完成页签键盘操作、桌面/窄屏及原有业务回归，再提交代码与四份规格。

非目标：真实上传服务与检测算法、自动案件总风险打分、人工复核意见/补证要求记录、报告导出、正式页面演示数据、草稿持久化、历史版本、3.3。本次内容只在当前案件页面保留，刷新或离开该页面不保证恢复；内部页签切换不属于离开页面。第四轮不改变检测选择默认值、适配器协议或公共业务状态。

### Modified Capabilities

无。
