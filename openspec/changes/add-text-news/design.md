## 前端阶段设计（2026-10-21）

本轮只实现浏览器端工作台，不宣称材料保存、链接抓取、文档解析、模型检测和报告存储已经可用。

- 页面分为“稿件提交”“检测结果”“历史与报告”三个页签。稿件来源支持粘贴正文、选择文档和填写新闻链接；AI生成风险与三审三校作为两个独立检测项和结果区域。
- 提交前校验标题、所选来源材料和检测项。链接仅接受HTTP或HTTPS；页面不直接跨站抓取新闻正文。文档前端只选择并展示文件信息，二进制上传和正文解析待公共文件服务接入。
- 页面通过`window.Veritas.api.invoke('/text/news', payload)`调用现有入口。当前暂定`payload`包含`action`、`material`、`checks`、`revisionNote`和`previousVersion`，只用于前端联调；正式字段需与公共材料/版本契约一起确认。
- 页面暂定读取`status`、`aiRisk.summary/findings`、`proofreading.summary/issues`。动态问题只用文本节点渲染；未知或缺失结果明确显示“服务未返回”，不补造分数。
- 只有成功响应才建立版本记录并启用JSON报告导出。内容修改后标记为待生成新版本；501或其他失败显示真实错误，并保留当前输入。
- 响应式布局复用项目现有断点，未引入框架、运行时依赖、CDN或客户端密钥。

## 三审三校检测设计（2026-10-26）

- 浏览器提交完整正文；服务端保留原文字符偏移，建立`paragraphId → sentenceId → start/end/quote`分层位置。新闻按最多20段或约6000字组成窗口，相邻窗口重叠1段，任何窗口都不在段落中间截断。
- 单段超长且缺少换行时，按完整句子组合为虚拟段落；报告仍返回虚拟段落ID和原文绝对偏移。模型引用的`paragraphId`与`quote`必须由服务端回查原文，无法匹配的条目丢弃。
- 每个窗口执行局部文字与逻辑审校；多窗口稿件追加一次基于各段前240字的全文一致性复核。重叠窗口结果按类型、段落、位置和说明去重。
- 当前只实现`proofreading`。前端保留AI生成风险入口但禁用并明确标记“暂未接入”；直接请求同时包含未支持检测项时，响应使用`notRunChecks`和`partial`，不得伪造分数。
- 模型适配器仅在Node.js服务端读取`TEXT_MODEL_API_URL`、`TEXT_MODEL_API_KEY`和`TEXT_MODEL_NAME`，只允许HTTPS端点；上游错误正文、端点和授权头不进入响应或日志。稿件作为JSON数据置于用户消息，系统提示明确将其视为不可信数据，降低稿件内提示注入风险。
- `TEXT_MODEL_PROVIDER=deepseek`时默认调用DeepSeek官方Chat Completions端点与`deepseek-v4-pro`，启用JSON Output、thinking和`high`推理强度；所有默认值均可由服务端环境覆盖，真实Key不写入仓库。
- 本地服务启动时自动加载项目根目录`.env`，仅接受`TEXT_MODEL_*`字段；进程或部署平台已有环境变量优先。`.env`由Git忽略，仓库中的`.env.example`不得包含真实Key。
- 新闻/小说分析请求JSON上限4 MiB（句级检测同时携带完整正文和片段用于一致性校验），新闻正文上限50000字；响应保存SHA-256内容哈希与实际覆盖段落/窗口数量。材料持久化、身份权限、异步任务和正式报告仍属于后续公共能力。

## 句级EGTE检测设计（2026-10-26）

- 浏览器按`。！？.!?`、成对省略号和段落边界切句，保留`segmentId/sentenceIndex/start/end/text`；`start/end`采用JavaScript UTF-16左闭右开区间。小数和常见英文缩写不在句点处误切，长句不按固定字数硬切。
- Node服务逐项验证编号、顺序、不重叠、范围及`content.slice(start,end)===text`，防止前端片段与完整正文不一致。中文调用`cred`，英文调用`raid`。
- Node首次调用时启动`scripts/egte_worker.py`常驻子进程。子进程从只读`EGTE_ROOT`导入`predict.py`，按需加载分类器并在后续句子和请求间复用Falcon与随机森林；一次请求中的句子顺序处理，不为每句加载模型。
- 默认部署路径为项目`/home/wyt/projects/aigcdetect`、模型`/mnt/vos-6d37s2q0/users/yh/models/EGTE_CRED_RAID_20261023`，可通过`EGTE_ROOT/EGTE_PYTHON_BIN/EGTE_GPU/EGTE_TIMEOUT_MS`覆盖。Python进程不接收DeepSeek密钥，也不监听网络端口。
- 每句返回状态、token数、未校准AI类得分和标签。少于20字符或算法拒绝的句子返回`null`得分与原因；页面按原文顺序展示，长原文块设置最大高度与滚动条。
- `predictedLabel=1`只显示为“疑似AI”；`aiScore`乘100并保留两位小数展示，但明确标注“未校准，非概率”。整组句级列表采用自然高度、最高640px后纵向滚动，避免长稿件把页面无限撑高；列表可在全部句子与`predictedLabel=1`的疑似AI句子之间切换，并保留总体统计。
- 共享EGTE说明要求去除首尾空白后至少20字符且至少3个Falcon token。前端将不足20字符的句子与同段相邻句组成最多两句的非重叠片段；服务端重新分句验证连续编号、完整覆盖和不跨段。两句合并后仍不满足算法条件则不评分，合并得分只属于整体片段。
- 三审三校问题新增`originalText`，只能取自服务端已验证的连续原文；前端在问题说明和建议下方单独展示。
- 模型结果校验的`receivedFindings/acceptedFindings/rejectedFindings`仅写入服务端`text_model_evidence_rejected`审计事件，并关联`requestId`与`scenario`。客户端只接收通过原文回查的问题，摘要和状态不暴露内部拒绝与校验过程；审计日志不包含稿件原文、模型原始内容或凭据。合法JSON缺少`findings`数组仍按上游结构错误处理，不降级为空结果。

## 新闻链接导入设计（2026-10-24）

### Goals / Non-Goals

**Goals:**

- 完成“公开新闻链接 → 后端安全获取与提取 → 前端预览编辑 → 用户确认稿件材料”的独立闭环，不依赖检测算法。
- 优先读取`NewsArticle`/`Article`结构化数据、Open Graph信息和`article`等语义正文容器，返回标题、正文、作者、发布时间、来源站点、提取状态、完整性状态及提示。
- 抓取失败、重新提取或未确认时保留现有稿件标题和正文；无可读正文时不得提交空材料检测。

**Non-Goals:**

- 不绕过登录、付费、验证码、WAF、客户端加密或仅浏览器脚本可见的正文，不保证适配所有新闻网站。
- 不在本轮实现新闻检测算法、文档解析、材料持久化或正式报告；`POST /api/v1/text/news`继续返回501。

### Decisions

1. **使用独立导入接口。** `POST /api/v1/text/news/import`接收`{ "url": "https://..." }`。成功结果包含`sourceUrl`、`finalUrl`、`siteName`、`title`、`author`、`publishedAt`、`content`、`extractionStatus`、`completeness`和`notice`；无法可靠识别的可选元数据返回空字符串。
2. **复用已验证的安全网页获取。** 服务端复用小说链接导入的公网HTTP/HTTPS校验、逐跳重定向校验、固定已解析公网地址、10秒超时、最多5次重定向和2 MiB响应上限。新闻导入不在浏览器跨站抓取。
3. **通用提取保持保守。** 优先解析JSON-LD中的`NewsArticle`、`Article`或`ReportageNewsArticle`；其次读取Open Graph、常见文章元数据和语义正文容器。正文必须达到最低可读条件，导航、脚本、表单、页脚和推荐区域不作为正文；候选不可靠时返回失败并建议粘贴正文。
4. **区分部分可读与未知完整性。** 页面出现登录、订阅、付费或“展开全文”等截断线索但仍有可读正文时标记`partial`；缺少足够完整性线索时标记`unknown`，不把字数当作完整性的唯一证据。
5. **先预览、后确认。** 提取结果只更新独立预览；用户可编辑标题和正文，点击确认后才保存确认稿及来源元数据。重新提取或失败不清空已确认材料；链接被修改后，旧确认稿不得用于新链接。
6. **检测仍使用确认后的材料。** 链接来源提交检测时同时携带确认后的`content`与`source`。部分或未知完整性的后续结果只能表述为“仅检测已导入内容”；当前检测服务继续返回真实501。

### Initial Site Verification

- 新华网公开文章`/politics/20261001/.../c.html`实测HTTP 200，可从`detailContent`语义容器提取标题、来源、发布日期和7,824字正文，完整性保守标记为`unknown`。
- 央视网、中新网、凤凰网和澎湃新闻的公开单篇图文样本均在服务端HTML中提供正文，但使用站点特有容器；提取器按域名限定这些容器规则，避免将宽泛类名用于其他站点。
- 验证或访问限制只依据页面可见文本判断，忽略脚本、样式和模板中的`captcha`等技术字样，防止把正常新闻误判为验证码页面；页面可见的验证码提示仍返回`ACCESS_RESTRICTED`。
- 常见中文新闻标点实体在正文归一化阶段解码，避免将`&ldquo;`、`&rdquo;`等原始实体带入预览和检测材料。
- 该结果仅证明当前页面结构可用；站点模板变化、登录/验证限制或仅客户端渲染时仍应返回失败，不降级为虚假成功。
