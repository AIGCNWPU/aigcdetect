# Proposal

负责人：两位组长。状态：空框架已接入，公共业务能力待实现。

## Why

为六位业务同学负责的10个检测场景提供一致的导航、任务和原材料引用边界，支持独立开发并通过PR集成。

## What Changes

- 已有：4个模块、10个独立空白页面、模块服务接入点、501业务接口、构建和检查。
- 待实现：正式身份和权限、文件存储、异步任务、检测结果、版本及报告。
- 按优先级提供统一样例、保存与版本、文件及解析预处理、任务配置和报告基础能力；具体供应安排见design。
- 非目标：提前实现算法、邀请成员或部署生产环境。

## Capabilities

### New Capabilities

- `shared-foundation`：场景框架及最少公共能力。

### Modified Capabilities

无。

## Impact

公共映射以[design](design.md)为准，业务实现分别归属10个工作包。
