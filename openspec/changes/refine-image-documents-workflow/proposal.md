# Proposal

需求来源：负责人自查（2026-11-15）。场景：2.3 AI证件与票据图片检测（含对外 API）。状态：实施中。

## Why

2.3 上线后经实际使用发现：模型链路命名混淆（mirror/SEED/DocShield 关系不清）、前端残留未消费的省份/高校研究入口、业务形态只支持“核心+辅助”整体核验而不支持零散单据鉴伪、对外 API 与成熟产品（TextIn 通用篡改检测）相比缺少直观结论（篡改分数、逐框置信度、可视化叠加图、耗时）与图像属性鉴别（模糊/手写/复印/翻拍）。

## What Changes

- **模型链路澄清与展示统一**：2.1 局部篡改=TruFor（通用图像域），2.3 局部篡改=SEED（票据文档域）；2.1/2.3 整图均为 DDA-H+（2.3 的 `mirror` 阶段名沿用 MIRROR 历史名，实际执行 dda_hplus）；DocShield-9B 仅为离线评测对照，不进线上链路、不双跑。
- **删除未消费的地区研究入口**：前端移除“规则适用地区/业务适用地区（省份）/业务发生日期”；服务端不再向语义复核注入省份政策研究引用；省份/高校研究数据移入研究归档。`jurisdiction`（中国大陆/其他）保留为服务端规则域开关（境外材料禁用中国票面格式规则），前端默认中国大陆。
- **双核验模式**：新增“单材料鉴伪”（每份材料独立：整图+篡改定位+单份内容核验，不做跨材料）与“多材料业务核验”（现有核心+辅助+交叉核验）两种模式，进入页面先选模式；单材料模式隐藏核心材料选择与关联确认。
- **对外 API 对齐成熟产品口径**：补 0–100 篡改总分（tamperScore）、逐区域置信度（tamperedLocation[].probability 于 2.3 补齐）、可视化叠加图（overlay，可选）、接口耗时（duration）、材料类别自动判断（materialType=auto）。
- **图像属性鉴别**：新增质量/来源属性输出（模糊、手写、疑似复印、屏幕翻拍、截图、扫描件，各带概率）与直观分数；v1 以可解释规则基线上线，v2 引入/训练轻量多标签分类头（翻拍优先复用开源 risa-recaptured 权重，其余属性自训）。
