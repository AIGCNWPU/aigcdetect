# AI音频检测

本目录负责模块定义、独立场景页面、业务服务和类型草案。

| 场景 | 页面文件 | 接口 |
| --- | --- | --- |
| AI音频伪造检测 | `pages/forgery.js` | `POST /api/v1/audio/forgery` |

当前 4.1 已实现演示页（实测样例、波形、结论与失败态）；业务接口仍抛出 `NOT_IMPLEMENTED`。其余能力可通过各场景工作包分别开发；修改同一 `service.js` 或公共定义前先与同模块成员对齐。完整分工见 [团队开发](../../../docs/TEAM_DEVELOPMENT.md)。

## 页面能力

- 音频/视频上传 → 真实调用推理服务（`?api=` 或本机自动探测 8000 端口），失败不影响离线样例演示；
- 长音频（>30 秒）展示窗口评分曲线，短音频只有单点、不画折线；
- **导出检测报告**：结果卡右下角按钮，走浏览器打印（`window.print()`）另存为 PDF，无第三方依赖；
  报告视图也可用 `?demo=<样例>&report=1` 直接打开，便于截图或自动化导出。
