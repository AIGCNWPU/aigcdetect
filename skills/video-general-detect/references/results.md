# 结果契约与边界

客户端兼容后端直接结果或 `{data: result}` 包装。完整JSON保留图片data URL、模型字段和上游证据；Markdown仅生成摘要，不丢弃原始JSON。

| 字段 | 解读 |
|---|---|
| `risk` | low/medium/high/unknown，风险分档而非真实性认证 |
| `summary`, `findings`, `scope` | 上游结论、线索和实际处理范围 |
| `coverage` | 仅采样内容；partial不能改称全片已验证 |
| `frames`, `segments` | 代表画面、采样窗口/采样点与关联时间；不延伸到未处理区域 |
| `persons` | 人脸轨迹与人物分组，如存在；不是身份认证 |
| `meta` | 模型原始分数、阈值、覆盖、标识/复核记录；版本间字段可能不同，应检查实际响应 |
| `aiGeneratedMarker`, `visualAiMarker`, `meta.aiMarker` | 元数据/文件名/可见AI声明；与模型判别分开 |

上游可能将文件标识赋值为100%、视觉标识赋值为99%；报告必须注明这是规则赋值。普通字符串扫描并没有做C2PA签名校验，也不表示已验证不可见水印。

## 故障处理

- health连接失败：检查专用端口和启动日志；不把原网页服务误当本包专用服务。
- modelReady/ready=false：检查权重路径、strict加载错误与依赖；不跳过缺失分类头。
- CPU进程很慢：解释采样窗口/人脸数量与预计开销；保留任务状态，不伪造进度百分比。
- 400/413/422：查看格式、大小、时长或解码错误，不自动改名/重编码后当作同一原始文件。需要转码时保存新文件并说明。
- 429：服务已有任务，等待后在用户仍需要时重试一次。
- 500/503：保留错误，不展示“低风险”。JSON和报告输出路径仅在成功后返回。
