# 统一部署（web + audio）

目标：**一个域名、一个端口**提供页面和 API，后续把它包装成对外 API / MCP 时只暴露这一层。

```
                ┌──────────────────────────────────────────┐
 browser ──────▶│ web  Node 网关  :8080                     │
 /api/…         │   /                     → dist/ 静态页面  │
                │   /api/v1/audio/*       → audio  :8000   │
                │   /api/v1/text|pdf|report → text :8010    │
                │   /api/v1/health        → 本地汇总        │
                └───────┬───────────────────────┬──────────┘
                        │                       │
              ┌─────────▼──────────┐   ┌────────▼──────────┐
              │ audio  FastAPI     │   │ text  FastAPI     │
              │ backend/server.py  │   │ 学术/新闻/小说      │
              │ 分离 → 掩码 → 鉴伪  │   │ （已有部署）        │
              └────────────────────┘   └───────────────────┘
```

## 一、两种起法

### A. 一键脚本（开发/单机）

```sh
cp deploy/.env.example .env        # 按机器改端口与模型路径
./deploy/start-all.sh              # 起 audio + web，等健康检查
./deploy/start-all.sh --web-only   # 后端在别处时只起 web
./deploy/stop-all.sh
```

日志在 `run/web.log`、`run/audio.log`，pid 在 `run/*.pid`。

### B. systemd（长期）

```sh
sudo cp deploy/audio-forgery.service.example /etc/systemd/system/audio-forgery.service
sudo cp deploy/aigcdetect-web.service.example /etc/systemd/system/aigcdetect-web.service
sudo systemctl daemon-reload && sudo systemctl enable --now audio-forgery aigcdetect-web
```

## 二、网关怎么分流

`scripts/serve.mjs` 里的 `resolveBackend(pathname)` 是唯一的路由表：

| 前缀 | 目标 | 环境变量 |
| --- | --- | --- |
| `/api/v1/audio/*` | 音频鉴伪服务 | `AUDIO_BACKEND_URL`（默认 `http://127.0.0.1:8000`） |
| `/api/v1/text/academic`、`/api/v1/text/humanize`、`/api/v1/pdf/*`、`/api/v1/reports/*` | 学术/文档后端 | `BACKEND_URL`（默认 `http://127.0.0.1:8010`） |
| 其他 `/api/v1/*` | 留在 Node 本地（新闻/小说/图片/视频等） | — |

`PROXY_BACKEND=1` 才启用代理；`PROXY_BACKEND=0` 时音频接口保持 501，避免本地开发误连生产。
`GET /api/v1/health` 会带上 `backends.{audio,text}`，方便一键确认代理指向。

## 三、音频接口契约

`POST /api/v1/audio/forgery`

```jsonc
// 请求
{ "audioBase64": "...", "fileName": "a.wav", "mode": "auto" }  // auto | single | dialogue
```

`mode=auto`（默认）先做说话人分离：

- 只有 1 位说话人，或第二位语音过短（< max(2s, 5% 时长)）→ 回退单轨结论（`data.mode = "single"`）；
- 2 位及以上 → 返回分人结果（`data.mode = "dialogue"`）。

```jsonc
// 分人结果
{
  "data": {
    "mode": "dialogue",
    "verdict": "A_fake",                 // both_real | A_fake | B_fake | both_fake
    "durationSec": 34.46,
    "speakers": [
      { "id": "A", "label": "SPEAKER_00", "segments": [[0.17,3.25]],
        "totalSpeech": 16.62, "pFake": 0.99999, "isFake": true, "fakeRegions": [] },
      { "id": "B", "label": "SPEAKER_01", "segments": [[3.78,6.51]],
        "totalSpeech": 12.5, "pFake": 0.000488, "isFake": false, "fakeRegions": [] }
    ],
    "raw": { "A": "{...}", "B": "{...}" },
    "threshold": 0.99593,
    "warnings": []
  },
  "requestId": "..."
}
```

前端只看 `speakers.length`：≥2 渲染分人视图，=1 渲染单轨视图——**不需要额外的"这是对话"标记**。

未配置分离器（`SPOOFDIAR_ROOT` 为空或依赖缺失）时：`auto` 静默回退单轨；强制 `mode=dialogue` 返回
`503 DIALOGUE_UNAVAILABLE`，不会编造分人结论。

## 四、为 API / MCP 包装做准备

统一在这一层之后做，好处是后端可以随便换：

1. **对外 API**：直接暴露 `web` 的 `/api/v1/*`（已带 `requestId`、统一错误码、`/docs/openapi.json`）。
   需要鉴权时在 Node 网关加一层，不必改后端。
2. **MCP**：已实现，见 [mcp/README.md](../mcp/README.md)。**一个 server、一个工具**：

   | 项 | 值 |
   | --- | --- |
   | 工具 | `detect_audio_forgery(audioUrl \| audioBase64, fileName?)` |
   | 传输 | stdio（`npm run mcp`）/ Streamable HTTP（`npm run mcp:http` → `:8787/mcp`） |
   | 转发 | `POST ${VERITAS_API_BASE}/api/v1/audio/forgery`，固定 `mode=auto` |

   **没有 `mode` 参数**：单人还是双人由服务端判断，工具只返回"整段结论"或"谁被伪造"。
3. **多实例**：`AUDIO_BACKEND_URL` 指向负载均衡即可水平扩展；音频服务是**单进程全局锁**（同进程串行），
   多卡部署时按 GPU 起多个实例、网关侧轮询。

## 五、已知限制

- 音频服务单进程串行（模型 18 GiB，单卡一个实例）；
- 长音频 ≤ 120 秒、上传 ≤ 80 MB，超限直接 413；
- 分人模式耗时约为单轨的 2 倍（一次分离 + 每人一次推理）；
- `mode=dialogue` 依赖 `spoof_diarization` 包与 pyannote token，未配置时按上面的降级规则处理。

## 六、验证清单

```sh
curl -s localhost:8080/api/v1/health | jq '.backends'
curl -s -X POST localhost:8080/api/v1/audio/forgery \
     -H 'Content-Type: application/json' -d '{"mode":"auto","fileName":"x.wav","audioBase64":"<...>"}' | jq '.data.mode'
curl -s localhost:8000/api/v1/health | jq          # 直连音频服务
open http://localhost:8080/#/audio/forgery         # 页面
```

`npm test` 里的 `tests/gateway.test.mjs` 覆盖了路由表、代理转发与"未开代理时保持 501"三种情况。
