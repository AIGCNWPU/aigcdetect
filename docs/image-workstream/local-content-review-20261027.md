# 本地核验输出、扩展材料与制度覆盖 · 2026-10-27

本轮继续 `add-image-documents`，修改生产规则及自动评测输出，没有调用外部API或本地语言模型。旧实验和旧查看目录保留。所有路径均相对项目根目录；实验路径以平台根目录为起点。

## 1. 页面内容从哪里来

| 内容 | 自动生成方式 | 实际边界 |
|---|---|---|
| 完整OCR文字块 | OCR对图像文字区域检测与识别，保留文字、原区域和识别分数 | 可能漏识别、错识别，不代表原件全部内容已读到 |
| 字段、角色、值、分数 | `ocr-fields.js`整合标签/正则、版式行列和段落提取；`content-fields.js`及`additional-content-fields.js`增加格式适配 | 识别出的全部文字另存；字段表只列已支持且有来源的业务字段，不是每句话都生成字段 |
| 逐项检查、状态、证据 | `review-plan.js`调用单份与跨份规则，再经`execution-assessment.js`和`review-presentation.js`汇总 | 是实际生产代码的自动输出，不是人工为这几张图写答案 |
| 中文原因 | `content-rules.js`的`explainLocalCheck`按原因码、字段及计算值生成 | 模板由开发者编写，具体金额、票种、字段、证据由本次运行取得 |
| 作者标注、人工核对 | 评测程序执行结束后单列 | 不作为字段提取或规则判断的输入，不是程序判定依据 |

未来走相同流程的文件，都会按实际识别到的字段保留结构和来源；受支持格式不同，字段数量和覆盖程度不同。未知格式、缺字段和歧义需保留，不能承诺每份材料均达到第0组的完整程度。

字段`confidence`为有关OCR标签/值/上下文区域识别分数的最小值，不是真实性或规则结论的概率。检查的PASS/FAIL/WARN/NEI分别表达本项正常、发现规则异常、发现需确认差异、未完成判断；执行等级A/B/C/D及路由由证据、识别质量、适用范围和上下文需求计算，也不等于模型准确率。

## 2. 已修改的实际规则输出

- 日期有效性PASS：`日期核验正常。` 不附加用户指出的实际业务日期声明。
- 同标识可见内容不一致：列出具体字段，追加`疑似文件遭遇篡改，请核对原件。`
- 金额：程序保留不含税金额、税额、应有合计、票面合计、差额与容差，以十进制整数计算，避免浮点误差。
- 发票号码与代码：输出适用票种、要求位数、实际位数及首位；已发现结构异常才追加疑似提示。NEI不写成已发现篡改。

第34组自动输出示例：

> 不含税金额1999.99元＋税额259.99元，应为2259.98元；票面价税合计1999.99元，相差259.99元，超过0.01元容差。疑似文件遭遇篡改，请核对原件。

> 按照增值税电子普通发票规则，发票号码应为8位；本次识别为7位。疑似文件遭遇篡改，请核对原件。

> 按照增值税电子普通发票规则，代码应为12位且以0开头；本次识别为13位、首位2。疑似文件遭遇篡改，请核对原件。

这些均来自本轮自动运行；不是人工往结果文件增加理由。

第02组作者分类为“税收完税证明”，实际图片为移动缴费详情。保留作者分类并记录冲突，按真实图像格式提取，不能据分类名强套税表。京东裸日期保存为`displayed_order_date`，不擅自解释为开票或业务发生日期。

迭代发现并修复：承诺函分块文字几何绑定把标题/正文当姓名；姓名与身份证标签同块导致号码遗漏；日期与“前”字拆块导致截止日期漏取；普通缴费凭证无税额列却套入价税检查。新增测试覆盖这些失败及反例。3份新增承诺函仍未唯一提取截止日期，不能视作不存在；机构制度及部分关联语义仍NEI。同户号跨供电单位只作为候选，不确认同一账户事实。未确认账户清单必须完整唯一时，列表不同不直接判违规。

开发使用了这些样本，因此这轮是开发回归，不是独立泛化评价，也没有覆盖全部CrossCred类别或图像。既有MIRROR、SEED或历史API结果不因本轮本地规则通过而自动升级。

## 5. 地区与高校：已研究不等于已执行

全国省级行政区与高校资料、985补充调研提供制度来源、材料清单及待实现审核点。当前运行的内容规则主要按文档格式、核心标识和可见业务关系组织，另有国家统一票号/身份结构等规则；没有完成每省、每所高校的完整可执行制度包。

`material-catalog.json`标记`proposed_not_institution_approved`；`catalog.js`返回`mandatoryPolicyEvaluated:false`、`rulesExecuted:[]`。`review-plan.js`对机构制度仍明确输出`institution_policy_not_configured`和NEI。地区选择不是自动加载了当地报销标准。金额上限、人员类别、有效时间、例外、审批要求和材料强制性均需逐条制度化后才能称为已执行，不能将全国调研正文直接当成程序规则。
