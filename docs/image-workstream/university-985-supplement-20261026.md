# 985高校校级审核材料补充调研

核查日期：2026-10-26。本文补充[全国研究总索引](national-review-research-20261026.md)，优先用校级财务、计财、资产管理等部门的近期文件替代此前学院、中心、基金会样例的不足。**学校发给各二级单位的规定，仍是校级规定；学院网页转载有文号、完整适用范围的校级原文，不等于学院自订规则。** 基金会、附属医院、独立法人研究院的制度则不能自动替代学校制度。

本文及[来源元数据](university-985-supplement-20261026.sources.json)是补充研究，不会自动运行。本轮没有修改生产正则、调用模型API或改动旧实验。来源中标记 `auto_executable: false`，不将“有官方链接”误报为“规则已实现”。北方及中部的详细补充见[天津、东北、湖北、陕西、山东分册](university-985-north-central-20261026.md)。

两份补充账本合计涉及22所985高校、25条来源记录，19条读到相关正文，其中重庆大学服务报道、同济大学窗口职责不计为实质材料规范；其余17条材料相关正文来自15所学校，仍包含年度专项、临时流程和日期待核事项。这里的“校级”不等于“该校所有业务通用”，也不等于39校全部制度已读或已完成生产规则。

## 2. 新增可读校级材料与候选审核点

以下“核心/一般/条件”是辅助审核平台的整理方式，不声称学校文件使用相同等级。固定日期、额度只有在学校、经费、业务、人员及适用版本确认后才能转为程序条件。

### 北京航空航天大学：燃料费和办公材料

[2026-04-21计财函字〔2026〕3号](https://jhcwb.buaa.edu.cn/__local/5/6C/56/27ADC7DC5110D1FFBCD75ACC9AF_0B732E5B_22F5B.pdf)全3页已读，发各单位，2026-05-01起按提交报销单日期实施。核心：电子发票；一般：项目经费类别、用车台账；条件：同月同经费号其他已报支出。拟核横向/纵向适用、台账行程、单票800元和月累计2000元、停车费配套提交。办公类物品不得直接用纵向经费列支；机器运行燃料与市内车辆燃料必须先分类。累计数据未齐不能判月度通过。

### 浙江大学：全校财务办事指南

[2025年5月指南](https://gjyxy.zju.edu.cn/_upload/article/files/49/ac/07d437174e19827023d43e067fdb/c2bb016a-4f92-4d71-9726-35fa3ee7f69b.pdf)151页全文可提取，重点阅读正文第5—11页，封面署名计划财务处，学院只是转载站。核心：预约单、发票；一般：明细及付款；条件：采购备案/入库、合同、遗失证明和审批。拟核主体金额一致、材料类别及经费类别决定的附件分支。危险化学品、普通试剂和其他材料不能合并一条规则；横向与纵向材料手续不同。指南后附旧制度摘录不被视为2025新制，不直接启用旧金额表。

### 华南理工大学：财务报销篇

[2025年9月校财务处指南](https://www2.scut.edu.cn/_upload/article/files/c6/17/caeaf9fc41fa9d69ecaff9f3ae78/7787f396-5f95-4971-9d6d-f654127d481a.pdf)39页全文可提取，重点阅读正文第4—7页。核心：网报单、票据；一般：付款及商品明细；条件：合同、采购结果、验收资料。拟核销售方与收款方、交易合计、合同主体及附件。教学科研设备、普通设备、软件、图书、外拨经费的合同条件不同，不能统一一个金额门槛；二级单位无授权不得充当合同主体。指南明确新规定优先，2026是否改用无纸化须另核，不能硬判“未打印即不合规”。

### 上海交通大学：外宾接待

[2025-05-20沪交外〔2025〕17号](https://gk.sjtu.edu.cn/Assets/userfiles/sys_eb538c1c-65ff-4e82-8e6a-a1ef01127fed/files/20250702/20250702135304535.pdf)9页全文已读，校级、印发即施行。核心：接待报销票据、获批来访预报；一般：来函/邀请、活动及人员证明；宴请时附清单，长期学术访问按条件附协议。拟核访问类别、主访/顺访、日期人数费用和承担方。不得把主访国际旅费与顺访城市间交通规则互换；本校在聘外籍人员、在籍学生及特定外专项目不直接适用；国际会议另按对应制度。

### 中南大学：全校报销管理

[2025-04-30中大财字〔2025〕10号全文](https://soa.csu.edu.cn/info/1102/9425.htm)31条已读，校务会通过、学校发各二级单位，学院转载；不是学院自订制度，校OA原件另待核。核心：报销单、票据；一般：审批、支付和明细；条件：合同、化学品平台订单、参会通知、租车/自驾审批、遗失替代证明。拟核单票1000元起的对公/垫付证据分支、收款人对应、租车自驾与交通补助重复、同一国际差旅拆分。收款主体不一致允许补合理支撑；不能仅凭字符串差异判虚假。横向职称交通例外单独处理。

### 厦门大学：大学生医疗报销

[校学生处2025-06-09材料说明](https://xsc.xmu.edu.cn/info/1015/105782.htm)正文已读，校级职能部门、仅符合条件的参保学生。核心：医疗票据与费用清单；一般：病历/出院材料、身份及基本医保结算；条件：转诊、异地、外伤责任材料。拟核患者对应、清单合计、就医日期、已结算与剩余支出，防止重复申请。校内正常教学、假期异地、急救有不同补证条件；不据文本判断诊断真伪。2024—2025缴费示例及保险比例不能无校验用于2026新学年。

### 电子科技大学：电子与纸质附件分流

[2025-12-30通知〔2025〕36号](https://www.jcc.uestc.edu.cn/data/Upload/1a367b8f00c2b5ca5c43d21f185168b1.pdf)为1页扫描件，已实际渲染阅读，发全校师生，说明2026逐步转智能平台。核心：预约报销信息、电子发票；一般：审批与业务附件；条件：纸质发票、审计定案表、签到原件等线下归档。拟核附件介质与归档分支、电子票据重复，不能对全电子业务强索纸质打印。该通知是流程依据，不提供差旅限额或税率规则。

## 4. 从材料说明转成可执行规则的具体要求

这些文档确实不能直接替代程序。每条候选应拆成“适用条件—必需字段—关系证据—确定性计算/条件—例外—输出—来源版本”，而不是把整段政策塞进正则。正则仅适合抽取标签与格式；累计金额、日期区间、经费类别、条件附件要用结构化条件与计算。

例如北航车辆费用规则需 `institution=BUAA`、提交日不早于2026-05-01、`expenseType=city_vehicle_fuel`、经费类别、发票金额、用车台账、经费号及当月历史报销；缺历史应输出“仅本次票面已核，累计额待补”，不能输出全项通过。中南租车差旅需确定同一人、同次行程和同日区间后，比较租车/自驾与交通补助；未证明属于同一行程时先补关系证据。浙大和华南理工相同材料名也必须绑定不同机构版本。

后续实施每条规则至少用：合规、明确错误、字段缺失、OCR低置信、条件不适用、允许例外六类样本验证。发布前由熟悉学校财务的人确认条款解释；本轮来源仅登记为研究候选，不假装已运行或已完成业务验收。
