# 任务2.3全国材料审核调研：北方11省区市证据分册

核验日期：2026-10-26。范围：北京、天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、山东、河南、陕西。

本册是全国调研的一部分，不等同于全国全部场景已经覆盖。逐地检索政府和高校官方信息，区分文件成文日期、页面发布日期、施行时间与获取完整程度。2023—2026年原始文件或操作指引优先；新网页转载旧制度不当成新制度。已读正文不等于已取得完整政策沿革，不能笼统宣称截至今天全部条款无修订。这里给出的是后续规则实现的证据和设计，**不是已经上线、已经通过真实数据集验证的规则清单**。

“内部角色”只供研究适用范围和材料责任，不应成为前端的公安/税务/高校身份选项。前端用“差旅报销核验”“采购付款核验”“证明材料核验”等功能名称。大学是不同治理类型的实例，不意味着一所大学代表本省所有学校。行政机关、高校、公司使用的规则不可互换。

## 证据等级与完成情况

- `body_verified` / `pdf_text_verified`：已获取正文/PDF文本并检查相关条款；不是只看到搜索标题。
- `search_excerpt_only`：仅搜索结果节选可见，附件未取到，不能投产确定性规则。
- `metadata_only`：仅标题、时间或目录可验证，条款内容未验证。
- 山东为特殊情况：已核济南转发正文，但省级附件未完成全文读取。

11/11地区都进行了实质检索和逐项分析；11地有政府相关正文证据，其中山东省级文件本体仍有缺口。10/11地区有高校正文实例，天津只有附件摘要；黑龙江已补东北林业大学2025报销长图的实际视觉核验和黑龙江大学2025铁路票据更新，哈工大2025项目另外标为历史案例。内蒙古最新高校材料表、哈工大新差旅制度仍受验证码/OA限制。不能将这些数字表述为“11省全部现行规则通过验收”。

材料分级中的“核心”是该审核目的的主对象；“一般”是通常的证明链；“条件必需”在条件满足时就是必需，不等于随意可选；“可选”用于解释例外或增强证据。下列分组是平台整理建议，具体法定/校定必需项以引用来源和适用条件为准，未在来源明确的分组不冒充政府清单。

### 1. 北京（110000）

- **政府依据**：[北京市财政局关于本国产品标准和异常低价问题的政策解读](https://czj.beijing.gov.cn/zwxx/2024zcjd/202603/t20260310_4553998.html)；成文 页面未单列，发布 2026-03-10；核验等级 `body_verified`；范围：北京市政府采购；解释财库〔2025〕30号、财办库〔2026〕2号。
- **代表高校**：[北京大学医学部财务报销手册，2024年4月修订](https://jcc.bjmu.edu.cn/docs/20240507094058364082.pdf)；成文 2024-04，发布 不另作推定；核验等级 `pdf_text_verified`；范围：北京大学医学部。

**审核目的与内部角色**：政府采购报价复核；医学教学科研日常报销；采购经办、评审人员、医学部项目负责人、会计。

**提交材料分级**：核心：采购需求及报价表，或报销单与发票。一般：预算/最高限价、采购合同，或商品服务明细。条件必需：被触发异常低价审查时的书面解释和佐证；达到医学部手册条件时的支付记录和查验结果。可选：独立价格参考、业务说明。

**本地核验与转交复核**：本地先比较项目、金额、抬头、单价数量与明细合计；低价只生成“需解释”任务，不能等价于虚假。医学部认可的抬头形式不能被统一字符串规则误杀。

**差异与例外**：异常低价的专业合理性、价格差异原因交人工或带上下文的复核；医学部2024手册不能替代其他高校制度。北航2026表只取得页面元数据。

**时效与缺口**：医学部手册2024版，需持续核对后续修订；北京采购2026解读较新。

**本地核验与转交复核**：本地比较姓名证件号、证明期间与用途日期、行程和票据关联；证明正文不等于本地能够访问公安记录。高校附件表仅检索摘要，设计中的材料项须标“待原文确认”。

**差异与例外**：天津线上证明办理条件不能推广全国；电子和纸质形式不可误判一方无效。天津科技大学材料表PDF403、南开PDF404是明确缺口。

**时效与缺口**：政府服务说明2026；高校2025摘要候选，尚不满足完整高校正文覆盖。

**时效与缺口**：省文件2024-11-05成文、2025-01-01施行；河北大学2025指南。阈值落规则前仍需绑定采购发生时间和后续版本。

**时效与缺口**：自治区2026新规已核验并识别旧版废止；内蒙古大学2026报销材料附件被验证码阻断，因此2023通知的现行性仍待校方确认。

**时效与缺口**：高校2025操作指南已补强，但不声称基础制度全部在2025新制定。[哈工大经管学院2025境外交流项目](https://som.hit.edu.cn/info/1011/23567.htm)有完整材料链，可作历史案例；项目行程截止2025-12-20，不当2026开放项目规则。哈工大2025新差旅制度OA正文仍未核。

**审核目的与内部角色**：采购验收后支付资料审核；高校差旅事项与补助核验；采购人、验收与财务人员；威海校区出差人员、审批人。

## 不同材料如何进入规则，而非任意两两比较

以下是根据各地证据归纳的平台设计，不是新增行政要求。

1. 以用户选定的核心材料建立事项：发票/报销申请、采购合同、资助申请或证明文件。保留发生时间、机构、经费类型、地区及规则版本。
2. 给辅助材料分配关系：发票→明细，合同→履约验收→付款，会议通知→审批→行程→住宿，资助申请→核准额度→支出→其他资助，证明→身份→用途。只比较明确关系及同一事项的汇总，不对全部文件做排列组合。
3. 本地执行格式、金额、日期、重复、关联主体和材料齐备性核验。每条结论附规则适用条件、字段来源、证据页/框和缺失原因。未知经费类型、年份边界、OCR读错等先标需补充，不能直接判造假。
4. 只有适用条件和证据足够的明显错误才直接给明确问题。合同实质履行、异常低价合理性、被批准的特殊行程、条文之间冲突等交解释审核；官方数据库真伪、真实交付、签名效力不能仅靠大模型意见变成已核实。
5. 地区和学校规则均带 `jurisdiction`、`organization`、`businessType`、`fundingType`、`effectiveFrom/Until`、`sourceId`、`verification`。不满足适用范围时返回不适用或待确认，而不是默认全国通用。

可分层生成的结果：**存在明确不一致**、**需补充材料/确认条件**、**未发现已覆盖问题**、**该事项尚无可用规则**。这些是内容审核结果，不是图像篡改标签，不能用“未发现规则冲突”证明没有篡改。

## 最新规则优先与禁止误用的例子

- 吉林2026规程明确替换2024采购电子化暂行规程，不能保留旧版为默认。
- 内蒙古2026履约验收办法明确旧版废止与存量衔接，验收时间、合同签订时间必须保留。
- 辽宁线上签约通知明确**不含大连**；这就是同省不能笼统合并的实证。
- 河北省、市、县限额和雄安/定州/辛集的适用层级不同，高校科研仪器还有目录排除。
- 铁路纸质凭证的过渡期已结束，不能用2024答疑把过渡期永久化。
- 哈工大2025特定项目截止期已经过去，只能复用材料关系作历史案例，2026政策须再取。
- 河南2024综合政策不能整份当2026有效，尤其付款期限须校验后续上位规范。
