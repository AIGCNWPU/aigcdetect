## 2. 已实现的修改

| 需求 | 本轮交付 | 重要边界 |
| --- | --- | --- |
| 场景调研 | 税票、采购、差旅、学校、身份、居住等 14 场景；北京/上海/西藏与特定机构分别记录 | 非全国规则普查；机构要求不因地区相同自动适用 |
| 本地优先 | 同行税率税额、0% 矛盾、一般计税算术、出差/合同起止时间 | 不验证税目合法性；免税/差额等不套一般算式 |
| 结果分级 | A 本地确定、B 语义、C 补证、D 未覆盖；逐项来源和覆盖计数 | 不是已校准置信概率；OCR 0.9 是工程门槛 |
| 单份/多份提示词 | 背景、必要原文、事实、核心关系、待审事项、固定 JSON 输出 | 低分文字不让模型猜；无关材料不发送 |
| 两种模式 | 默认脱敏，明确选择可用原文；本地规则始终本地执行 | 严格脱敏可能省略自由文本；原文模式也不传整份文件 |
| 智能复核 | 官方文本接口、一次任务预算、版本缓存、超时、输出与引用校验 | 本轮未启用真实外部请求，审核质量未实测 |
| 政策背景 | 固定官方研究目录按功能/地区提供少量参考 | 不做实时检索；适用性未确认，不能直接判政策合规 |
| 用户结果 | 问题、解释、相关材料、补证动作、复核摘要；技术详情折叠 | 本地冲突不能被模型“合理”覆盖；未执行不显示通过 |
| 等待提示 | “当前正在检测，请您耐心等待~” | 实际浏览器已检查 |

机构角色只出现在内部研究材料，不新增身份选择器或身份权限。前端继续使用 VERITAS 智鉴的五个核验功能。

## 3. 代码如何组织

以下 `server/` 均指 `src/modules/image/documents/server/`。

| 文件 | 职责 |
| --- | --- |
| `review-policy-catalog.json` | 官方研究来源、场景映射、机构和地域边界、论文来源；全部不自动适用 |
| `business-rules.js`、`document-rules.js` | 新增同行计税/起止日期规则及接入已有单份规则 |
| `ocr-fields.js`、`vat-layout.js`、`docx-fields.js` | 显式字段和发票行几何提取，保留来源及行范围，防跨行/跨页串用 |
| `review-plan.js` | 沿用核心材料计划，传递确认关系的金额/日期/票据范围 |
| `execution-assessment.js` | 规则结果与执行度分离，生成本地/语义/补证/未覆盖事项 |
| `semantic-review.js` | 脱敏或原文证据包、静态政策参考、响应校验、缓存和单任务调用预算 |
| `review-presentation.js` | 合并视觉线索、本地冲突、复核说明与待补项；成功页的疑点不因其他页失败被隐藏 |
| `review-workflow.js` | 保留模型顺序及失败隔离，收集来源绑定正文，规则之后按需复核并汇总 |
| `review-service.js` | 验证模式、地区和日期；继续提供异步任务状态与私有结果存储 |
| `src/modules/image/documents/prompts/deepseek-semantic-*-v1.txt` | 新的中文脱敏/原文提示词；旧 `deepseek-target-review-v1.txt` 保留给历史流程 |
| `src/modules/image/pages/documents.js` | 地区日期、复核开关、信息处理模式、等待、用户结果与详情 |
| `scripts/openapi.mjs`、`docs/openapi.json` | 新请求选项与结果字段的接口描述 |

`semanticReview` 状态为 `completed/not_run/failed`；事项结论为 `reasonable/issues_found/needs_more_information`，任务的 `partial` 仍表示处理覆盖不完整。它们与规则 `PASS/FAIL/NEI` 不是同一个含义。

## 6. 已通过与仍待完成的分界

本轮的研究、确定性规则增量、执行分流、双模式构包、受控语义服务、结果页及上述工程验证已完成。第 8 组任务的完成只指此增量，不代表工作包整体完成，也不替代以下验收：

1. **真实语义效果**：本轮 API 请求为 0。须在少量授权公开/受控材料上实际调用，人工核对合理与矛盾解释、原文/脱敏差异和 token 成本，再评估阈值；不以模拟响应替代效果验收。
2. **独立中文业务材料包**：仍缺有真实关联、制度、例外及正确答案的独立留出集。需要分别标注字段、规则适用、跨文件关系和语义结论。
3. **机构制度接入**：研究目录已存在，但尚无机构制度选择/上传、条款生效期验证和受信政策证据模块。地区＋业务日期不足以判断政策适用；地方金额限额未启用。
4. **最新政策核查**：当前只传固定研究背景，不自动联网查当期法规。依赖最新政策的项目仍待有效来源，不让模型凭记忆放行。
5. **脱敏覆盖**：当前对无法确认安全的自由文本省略，会影响可判事项。需要基于真实标注扩充脱敏与业务词表，并量化遗漏和泄漏，不能直接放宽为任意文本外发。
6. **本轮视觉全链实测**：没有新增 MIRROR/SEED GPU 推理；原顺序和失败隔离有回归测试，历史模型验收记录保持原口径。
7. **平台公共能力**：认证、账户级调用配额、长时存储、完整脱敏报告导出、官方身份/税务查询仍未接入。新建任务会有新的一次调用额度，不能把单任务预算当成全站限额。

建议下一阶段先补机构制度与有标注材料包，再进行小批量真实语义验收；将错例分别归入解析、关系、规则适用、信息损失、模型推理和政策证据，按类别改进。继续使用已有 `add-image-documents`，不凭本轮单元测试数量关闭整个 2.3 里程碑。
