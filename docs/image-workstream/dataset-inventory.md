CrossCred实际21类材料计数：完税证明80、纳税证明23、无欠税证明32、手持承诺函23、缴费详情30、生活缴费凭证6、授权书8、销售合同10、购销合同2、房屋租赁合同2、商用办公室租赁合同4、小程序信息12、出库单2、借条12、增值税电子普通发票5、在职证明4、常住人口登记卡2、淘宝网店铺经营证明19、收入纳税明细6、营业执照2、京东订单2。78组中76组完整，3个图片引用缺失；没有逐图真伪真值或像素mask。

该分组集是目前最直接的跨内容核验资源，但作者自然语言异常解释仍须审查业务前提。例如同身份号不同账户、同用户号不同地址不能在缺少有效期/账户范围时自动升格为真实业务错误。评测应先将适用标注人工结构化，选定核心，记录关联前提和应发现的字段差异；同组、同源、相同模板变体不跨开发/留出划分，冻结规则和提示词后再跑留出。

分开评测：OCR/字段精确率与缺失率；适用关系下冲突检出、误报及NEI覆盖；来源/页/字段定位；解释证据引用和无依据推断。额外构造明确标注的工程对照组：改过但计算正确、无视觉修改但内容矛盾、合法分期/退款、角色不同、同名不同人、材料缺失。受控对照不得与真实数据成绩混算。全对枚举不用于生产核验；按核心邻接和显式集合计数验证增长。

FCTM仅适合先测SEED像素IoU/F1、区域定位和工程回映，不支持跨材料矛盾评估，且10种变体不可拆成独立训练/测试模板。CrossCred脱敏处理与真实篡改区域未分离，不直接当SEED像素定位真值。

中文公开开发材料还有3份PDF共12页（食品采购票6、设备票5、税务空白票样1）、郑商所指引PDF9页，以及 `datasets/chinese-business-forms-20261022/` 的科研预算表/出差审批表2份DOCX。均可测解析与部分抽取/规则，但无真实篡改或跨文件配套真值。DocTamper与RTM仍不计已下载完整数据集。
