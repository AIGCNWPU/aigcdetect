## 已审阅的返回问题

- 出库单：正确报告客户与电话差异、日期相同。单份结论因无金额/付款条件而判信息不足，这属于采购目标过宽，不能解释为出库单本身必须含结算条件。unsupported_field仍被错误描述为未取得提取结果。
- 在职证明：三对核心—辅助文件姓名差异均检出。号码校验失败和单位名称缺失可能来自数据集替换/遮盖，不能作为真实业务造假的额外检出成绩。模型“同号不可能对应不同姓名”的绝对说法未考虑合法更名等情形，产品应报告差异并要求核对身份/版本，而不是据此确定造假。
- 常住人口登记卡：正确指出同号不同姓名，额外将“两份都写长子”解读为“出现两个长子”，这是对材料版本/户关系的过度推断，不属于独立矛盾。应保留姓名差异，不把共享正常字段扩展成新错误。对登记日期和串行OCR的提醒应区分识别缺失与原件缺失。
- 营业执照：检出经营者陈*佳/李*山不同，正文主动提出版本/换发的可能性；但告警措辞比正文更强。额外提出名称“个人独资”与登记类型、“美容馆”与珠宝经营范围不匹配，这些属于模型发现的待核实事项，未对照适用登记规则，不能计为确认错误。两个跨文件事项重复，且通用问题仍要求核对营业执照并不承担的付款/履约条款。
