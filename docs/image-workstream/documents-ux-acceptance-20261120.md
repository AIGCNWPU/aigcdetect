# 2.3 界面修复与正式部署核查（2026-11-20）

## 修改内容

- 核验入口统一为发票核验、证件核验、票据核验、其他核验；后端新增 `receipt_review`、`other_review` 目的，智能核查背景保留选择的目的，不默认回落到发票业务。原采购、收付款、报销接口目的保留兼容。
- 手动材料类型默认“智能选择”，移除科研审批、项目审批、出差审批、验收记录、证明选项。底层识别类型与历史结果仍保留；选择票据核验不再强制把未分类材料转换为收据。
- 删去目的材料建议、非中国大陆格式说明，以及智能核验结论中的单材料/任务级/未校准等技术小字。
- 图像标记状态按材料 ID 保存；预览与位置弹窗同步。取消疑似修改/模糊标记后，任务轮询、完成后的重绘及切换文件不会自动重新选中。主动点击“查看疑似修改区域/模糊位置”仍会打开对应标记。
- 文件列表显示“删除”和“全部清空”。清空会释放预览 URL，清除结果、核心材料、关联确认及图层状态；后续新请求只包含新列表中的材料。运行中的任务暂不支持删除或清空。
- 智能核查证据卡片桌面三列、平板两列、手机一列；默认仍按原来的折叠方式展示。
- 保留接手时已有的智能核查材料名称和覆盖数量改进；跨文件结论提示不再把“缺少单文件结果”描述成“单文件未发现疑点”。
