# 固定图像案例与来源诊断呈现

## 交付

通用图片页的固定案例位于上传工作台之后、Benchmark之前。桌面按原图、实际区域标记、结果与来源诊断三栏展示，手机纵向排列。案例不加入用户文件列表，不再调用example接口；上传、清空均不影响静态案例。移除原真实样本及漏检样本的前台展示，并移除评测区QWEN-IMAGE-BENCH标头。历史评测文件未改写。

来源信息改为统一卡片：格式、尺寸、内容凭证状态、元数据、诊断缩略图与文件指纹。诊断图可点击放大，支持关闭按钮、背景和Escape关闭。凭证缺失独立展示，不改变AI分数。

## 数据来源与资产

沿用2026-10-31实测结果 visual-8（Qwen-Image-Bench / gpt-image-2 / prompt 1）的机械腕表图片。模型分数0.9492491483688354，实际标出6格响应。没有改变检测阈值、标记位置、分数或透明层内的像素。

- `public/image-examples/watch/`：原图展示副本、实际透明定位层、细节分布图及来源清单。
- `src/modules/image/general/example.js`：生成的静态展示数据。
- `scripts/image-validation/build-image-showcase.mjs`：验证原文件SHA-256后导出已测产物，无推理/API调用。
- `scripts/build.mjs`：将案例静态资产复制到dist。

复跑导出需设置AIGC_PLATFORM_ROOT并保留原实验文件；已导出的前端案例可以随Git与构建迁移，无需运行时模型或示例API。PNG案例没有压缩差异结果，页面不伪造该图层。

## 兼容与验证

修复通用图片上传与轮询对总项目已解包API响应的兼容；仍校验结果ID、完成状态和有效结论。本页独立滚动适配不修改其他模块。

494项Node测试通过；检查、构建、冒烟、OpenSpec严格校验通过。浏览器验证：屏蔽示例API时仍显示固定案例；上传清空后案例保留；标记开关、诊断放大关闭、390px布局、真实客户端的模拟排队/轮询响应通过。资产SHA-256与实测导出一致，6个区域来自原始cells。

本次没有新增GPU推理或付费大模型调用，使用已验证模型产物。案例用于功能展示，未作为新一轮模型准确率结果。

## 批量导入与等待队列

通用图片支持图片及ZIP混合选择，总计100张；单图10 MB，图片合计1000 MB，单ZIP100 MB。ZIP在浏览器分块解压，限制条目数、图片数与实际解压字节，不解压嵌套包。有效图片逐张上传检测；不支持RAR/7z。

服务端按FIFO顺序执行；无空闲GPU时返回queued、queuePosition和等待提示，每15秒重新检查，实际开始推理后才计算推理超时。排队和任务记录目前保存在单个服务进程内，服务重启后不恢复；浏览页面必须保持打开以继续提交后续图片。

验证：11项相关Node测试通过，覆盖GPU等待到自动恢复、两任务顺序及无并行推理、ZIP目录图片、101张截断、超限解压、损坏包；浏览器验证ZIP导入100张及排队提示、上传轮询和移动端布局；项目check、build、smoke及OpenSpec严格校验通过。资源恢复测试使用可控GPU选择器，未占用其他用户GPU、未调用外部模型API。

## 结果区浏览改版

新增结果区上一张/下一张、当前序号、文件名及附近7张缩略图；支持结果区键盘左右键，切换遵循筛选集合，首尾禁用，后台处理不强制改变浏览中的图片。浏览工具条随结果区滚动吸顶，移动端压缩为箭头按钮。每图原有图层选择保留。

分数来源已核对：DDA-H＋模型logit经sigmoid后取得fake_probability，显示乘以100保留1位小数；分类阈值为0.5。区域遮挡响应和元数据诊断不参与重新加分。

12项相关Node测试及浏览器测试通过，包含100张ZIP浏览、方向键、缩略图、首尾按钮、筛选序号与移动端无溢出。构建及项目检查通过。页面检查使用已有实测结果模拟接口回包，未发起新模型推理。
