# 全图特征分布与展示升级（2026-11-03）

## 实现与分数口径

通用图片正式上传与固定示例统一展示“AI 特征分布”。整图分类继续使用发布模型原来的中心预处理，score、阈值、Benchmark数据不变。新增分块分数仅用于空间分布，不替换分类结果，也不等于像素级AI面积。

`src/modules/image/general/spatial.py` 将分析副本最长边限制为1024，使用336窗口、最多168步长覆盖全部边角，小图对称填充。最多36个窗口，批大小4。按正值的中心权重汇总重叠窗口得分；固定0至1映射蓝至玫红，不按每张图重新拉伸。后台保存分析尺寸、源图坐标、窗口分数和logit。此版本是单尺度重叠窗口评分，不宣称实现多尺度分割或新的遮挡logit算法。原双遮挡记录仍保留，但不作为新版默认图。

`analyze.py` 在原分类及遮挡分析后生成 `spatial` 和 `diagnostics.layers.aiFeatures`。分类专用调用保持原行为；没有额外外部API调用。

前端 `pages/general.js` 默认展示新特征图；提供原图切换、透明度、统一弱强色带。移除区域块数，辅助诊断移除均值数字，显示用途说明；凭证缺失显示“此文件未附带来源记录”，不影响分类分数。老报告仍能查看已有遮挡图，不虚构全图分析完成。

示例生成脚本 `scripts/image-validation/build-image-showcase.mjs` 从新实测结果读取图层，校验原图SHA256，保留完整窗口记录到示例provenance.json。历史运行文件未改写。
