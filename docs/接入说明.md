# 场景接入

前端模块定义在 `src/modules/<模块>/definition.js`，独立场景页面在 `pages/<场景>.js`。页面函数接收 `(container, route)`，在container中挂载自己的DOM；新闻和小说页面已有工作台，其余场景仍保留框架入口。

模块 `pages.js` 和 `src/modules/registry.js` 统一注册页面。`src/app.js` 也暴露 `registerPage(path, renderer)` 供后续覆盖页面。前端入口示例为 `#/text/news`。

检测后端模块入口为同目录 `service.js`，由 `src/server/registry.js` 分发。新闻和小说已接入句级EGTE检测及各自的大模型审校能力；其他场景仍抛出未实现错误。新闻和小说网页导入分别由`src/modules/text/news-import.js`、`src/modules/text/novel-import.js`提供独立预处理能力。

前端统一调用：

```js
import { createAiScoringSegments } from '../src/modules/text/ai-segmentation.js';

const { api } = window.Veritas;
api.configure({ baseUrl: '' });
try {
  const content = '需要检测的第一句。需要检测的第二句。';
  const response = await api.invoke('/text/news', {
    action: 'analyze',
    material: { title: '示例稿', content, language: 'zh', aiSegments: createAiScoringSegments(content) },
    checks: ['ai-risk', 'proofreading'],
  });
} catch (error) {
  console.log(error.status, error.code);
}
```

页面实际复用`src/modules/text/ai-segmentation.js`，其`start/end`是JavaScript UTF-16左闭右开区间。20至29字符的短句优先与同段相邻句组成最多两句的片段；小说还允许相邻且各自仅含一句的短段成对合并。超过100字符的长句优先按软标点切分，无合适标点时按字符边界均衡切分，并保证每段不少于20字符。服务端使用同一规则重新分句并拒绝编号遗漏、非法跨段或与完整正文不一致的片段。新闻和小说在送入算法前只对副本执行NFKC、空白及危险不可见字符归一化，该副本是合法Markdown兼容纯文本，展示原文和位置保持不变；8012因片段内容返回413、422或500时会有限二分隔离异常片段，其余片段继续评分；全部片段持续500、400契约错误和其他系统性服务故障仍整体报错。合并片段的`aiScore`属于整个连续片段，不是任一单句或单段结论，且所有`aiScore`均为未校准AI类得分；三审三校的`originalText`和小说水稿结果的`originalText/references[].quote`用于展示问题原文。

新闻公开正文链接导入：

```js
try {
  const article = await api.importNewsArticle('https://example.com/news/article');
  console.log(article.title, article.author, article.publishedAt, article.completeness);
  // 先让用户预览、编辑和确认，再把 article.content 作为链接来源的稿件材料。
} catch (error) {
  console.log(error.status, error.code, error.details);
}
```

新闻导入优先使用页面中的`NewsArticle`/`Article`结构化数据、Open Graph信息和语义正文容器。当前支持公开、服务端直接输出可读HTML的单篇新闻页；仅客户端渲染、登录、付费、验证码、WAF或无法可靠识别正文的页面会返回失败并保留原输入。

小说公开章节链接导入：

```js
try {
  const chapter = await api.importNovelChapter('https://mip.ciweimao.com/chapter/113775098');
  console.log(chapter.workTitle, chapter.title, chapter.extractionStatus, chapter.completeness);
  // 先让用户预览、编辑和确认，再回填作品名称并把 chapter.content 加入章节列表。
} catch (error) {
  console.log(error.status, error.code, error.details);
}
```

成功结果中的`workTitle`为作品名称，`title`为章节标题；作品名称无法可靠识别时`workTitle`为空字符串，用户可在预览中补充。用户点击“确认填入章节表单”后，非空的预览作品名称会复写当前作品名称；只提取但未确认或提取失败时不会改动主表单。

小说发布平台选项包括刺猬猫、飞卢、纵横、番茄、起点、晋江、17K、咪咕和未知平台，表单通过点击展开选择并在折叠时显示当前平台。链接输入会按官方域名自动匹配；AI分析优先展示平台AI专项规则，没有专项规则时使用通用创作者协议，重复/水稿分析始终使用通用创作与内容规则。平台规则只供人工核对，不参与检测分数或标签计算。

导入服务只接受公开HTTP/HTTPS单章节正文页，逐跳校验公网地址，不执行页面脚本，也不绕过登录、付费、验证码、WAF或动态字体混淆。当前明确适配刺猬猫、飞卢和纵横的公开可读章节；目录页、受限页或识别失败页保留原输入并建议改用具体章节链接或粘贴正文。

客户端新增独立模块时更新 `scripts/source-files.mjs` 打包列表；服务器文件不得加入该列表。构建后的离线 `dist/index.html` 用于导航预览，业务联调使用 `npm run dev`。

通用视频检测的独立服务配置见 [通用视频检测说明](video-general-integration.md)。
