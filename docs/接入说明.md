# 场景接入

前端模块定义在 `src/modules/<模块>/definition.js`，独立场景页面在 `pages/<场景>.js`。页面函数接收 `(container, route)`，在container中挂载自己的DOM；未实现页面不创建内容和业务请求。3.2 人物换脸与深度伪造检测已提供独立前端适配入口，见[人物换脸与深度伪造检测说明](video-deepfake-integration.md)。

模块 `pages.js` 和 `src/modules/registry.js` 统一注册页面。`src/app.js` 也暴露 `registerPage(path, renderer)` 供后续覆盖页面。前端入口示例为 `#/text/news`。

后端模块入口为同目录 `service.js`，由 `src/server/registry.js` 分发。当前始终抛出未实现错误。实现时先完善请求和结果约定，并在HTTP层接入输入、权限和校验，再调用真实服务。

前端统一调用：

```js
const { api } = window.Veritas;
api.configure({ baseUrl: '' });
try {
  const response = await api.invoke('/text/news', {});
} catch (error) {
  console.log(error.status, error.code); // 当前为501 / NOT_IMPLEMENTED
}
```

客户端新增独立模块时更新 `scripts/source-files.mjs` 打包列表；服务器文件不得加入该列表。构建后的离线 `dist/index.html` 用于导航预览，业务联调使用 `npm run dev`。
