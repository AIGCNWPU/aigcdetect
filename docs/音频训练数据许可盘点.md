## 二、逐项说明

### 1. ASVspoof 2019 — ODC-By 1.0 ✅

- 来源：<https://datashare.ed.ac.uk/handle/10283/3336>（DOI 10.7488/ds/2555）
- Edinburgh DataShare 的 API 元数据里 `dc.rights` 明确写 "Open Data Commons Attribution License"。
- ODC-By 允许商用，义务是**署名**（给出数据库、作者、许可链接）。
- 音频源自 VCTK（CC BY 4.0），上游同样干净。

### 2. PartialSpoof — CC BY 4.0 ✅

- 来源：<https://zenodo.org/records/5766198>（v1.2）
- 代码仓库 `nii-yamagishilab/PartialSpoof` 是 BSD-3-Clause，但**数据许可以 Zenodo 记录为准**，即 CC BY 4.0。
- 音频基于 ASVspoof 2019 LA + LibriSpeech 拼接，两者均为可商用许可。

### 3. SINE — 未声明许可 ❌

- 这是 13 个里**最难查的一个**，配置里只写 `sine`，全文没有出处。
- 实为 **SINE = Speech INfilling Edit**，出自 NVIDIA/台大《Detecting the Undetectable》(SLT 2024, arXiv:2501.03805)。
- 用**复现版 Voicebox** 在 LibriLight medium 上生成（转录来自 LibriHeavy），共约 3.5 万条 6–8 秒片段。
- 问题：论文只说 "will be made publicly available"，**没有任何许可声明**，也没找到公开下载入口。按默认规则＝未授权。
- 另注：Voicebox 官方代码/权重从未公开，SINE 是用**自行复现**的 Voicebox 生成的，这意味着它无法通过"上游许可"追认。

### 4. WaveFake — CC BY-SA 4.0 ⚠️

- 来源：<https://zenodo.org/records/5642694>
- **ShareAlike**：允许商用，但要求衍生作品以相同许可发布。
- 把 CC-BY-SA 数据拿去训练模型，模型本身是否构成"衍生作品"在法律上**没有定论**。保守做法是：要么排除，要么仅用于评测不进训练集。

### 5. CodecFake — CC BY 4.0 ✅

- 来源：<https://huggingface.co/datasets/rogertseng/CodecFake>（Interspeech 2024）
- 卡片明写 `license: cc-by-4.0`，基于 VCTK（CC BY 4.0）做成，链路干净。

### 6. PartialEdit E1/E2 — CC BY 4.0 ✅

- 来源：<https://zenodo.org/records/18829689>（Interspeech 2025，University of Rochester）
- 注意：论文里四个子集只放了 E1（VoiceCraft）和 E2（SSR-Speech），**E3/E4 因 Audiobox 许可限制未发布**。
- 这反而是个好信号——作者在上游许可上做了切割。发布出来的部分就是 CC BY 4.0。

### 7. VCTK 0.92 — CC BY 4.0 ✅

- 来源：<https://datashare.ed.ac.uk/handle/10283/3443>（DOI 10.7488/ds/2645）
- 元数据 `dc.rights` = "Creative Commons Attribution 4.0 International Public License"。
- 是 ASVspoof2019、CodecFake、PartialEdit 的共同上游，源头干净很关键。

### 8. LJ Speech — Public Domain ✅

- 来源：<https://keithito.com/LJ-Speech-Dataset/>
- 文本（1884–1964 年出版物）与录音（LibriVox）均已进入公有领域；数据集卡标 `unlicense`。
- 无署名义务，最干净的一个。

### 9. EmoFake — CC BY-NC-ND 4.0 ❌

- 来源：<https://zenodo.org/records/12806228>（CCL 2024）
- **NC 非商业 + ND 禁止演绎**，是 13 个里限制最严的。
- ND 尤其要命：用它训练模型本身就可能被认定为"演绎/改编"。不是"内部用用没关系"能糊过去的。

### 10. SpeechFake — CC BY 4.0，但带 GPL 例外 ⚠️

- 来源：<https://github.com/YMLLG/SPEECHFAKE>
- 主体是 CC BY 4.0（Ant Group），**但 LICENSE 自己列了例外**：ChatTTS、EdgeTTS、Seed-VC 是 **GPL-3.0**，FireRedTTS 是 MPL-2.0，并明确写 "their respective licenses may apply"。
- 也就是说：数据名义上可商用，但其中一部分样本由 GPL 工具生成，这部分的权利链是不确定的。
- 保守做法：只取非 GPL 工具生成的子集（元数据里有 `generation method` 字段，可筛）。

### 11. DailyTalkEdit — Apache-2.0 ✅

- 来源：<https://huggingface.co/datasets/wsntxxn/DailyTalkEdit>
- 上游 DailyTalk 仓库是 MIT，与 Apache-2.0 相容。
- 注意：这是 HoliAntiSpoof 作者自己造的集，所谓"语义影响"标注是 **Gemini-2.5-Flash 生成**的，文本改写也是 Gemini 做的。**数据许可干净 ≠ 标注来源干净**——如果要绕开这条，需要自己重标。

### 12. Fake-or-Real (FoR) — 未声明许可 ❌

- 来源：<https://bil.eecs.yorku.ca/datasets/>（York University, APTLY Lab）
- 官网只给下载链接和四个版本说明，**通篇没有许可声明**；GitHub 无官方仓库；HF 上的都是第三方转存（且未标许可）。
- 和权重一个道理：无声明 ＝ 默认保留所有权利。
- 但它是最常用的 TTS 检测基准之一，**很可能只是作者漏写**——发一封邮件给 APTLY Lab 大概率能拿到明确答复。

### 13. In-the-Wild — Apache-2.0 ✅

- 来源：<https://deepfake-total.com/in_the_wild>（Fraunhofer AISEC）
- 页面明确写 "licensed under the Apache License, Version 2.0"。
- 注意：数据是从社交媒体采集的公众人物音频，**数据集许可不等于肖像/声音权授权**。做 to B 产品时如涉及具体人物，需另行评估。

## 三、结论与建议

### 3.1 能直接用于商用重训的 8 个

```
asvspoof2019  partial_spoof  codecfake_ntu  partial_edit
vctk          ljspeech       daily_talk_edit  in_the_wild
```

这 8 个覆盖了：TTS、VC、编解码重合成、部分伪造定位、单人/对话、真实野采、多说话人干净底料。
**缺的是**：无缝编辑（SINE 原本覆盖）、情绪伪造（EmoFake 原本覆盖）、商业 TTS 系统（FoR 原本覆盖）。

### 3.2 需要决策的 2 个

- **WaveFake**：建议只进**评测集**，不进训练集，避免 ShareAlike 争议；
- **SpeechFake**：可用，但按 `generation method` 字段**剔除 ChatTTS / EdgeTTS / Seed-VC / FireRedTTS 生成的样本**。

### 3.3 需要联系作者拿授权的 2 个

- **FoR** → APTLY Lab（York University），大概率只是漏写；
- **SINE** → NVIDIA / 台大作者（arXiv:2501.03805），需明确是否发布、以何许可发布。

### 3.4 必须替换的 1 个

- **EmoFake**（NC-ND）：建议自采情绪伪造数据，或改用可商用的情绪 TTS 自建。

### 3.5 关于"复现"的现实提醒

即使数据全部合规，复现 HoliAntiSpoof 仍有两项非数据成本：

1. **标注**：语义影响标注和对话改写都由 Gemini 完成，商用需自建标注流水线；
2. **算力**：SFT 20K steps（batch 64，7B 主干 + 音频编码器全量微调）+ ICLFT 5K steps。

因此更现实的排序仍是：**先谈原模型授权 → 不行再用上面 8+2 个集重训 → 同时用云 API 兜住对外交付**。

## 四、缺口补位：可商用的替代数据集

被砍掉的 3 个集各管一块能力。经核实，其中两块有**许可更干净的现成替代**，第三块需要自造。

### 4.1 补 SINE（部分伪造 / 语音编辑）— 有替代 ✅

| 数据集 | 许可 | 规模与内容 | 来源 |
| --- | --- | --- | --- |
| **LlamaPartialSpoof** v1.0.b | **CC BY 4.0** | 6 个 TTS 模型 + LLM 驱动的改写；含 crossfade、cut/paste、overlap-add 三种拼接方式；带 segment 级起止标注 | <https://huggingface.co/datasets/HaoY0001/LlamaPartialSpoof> |
| **HQ-MPSD** v1 | **CC BY 4.0** | **8 语种**（英/法/德/意/荷/波/西/葡）；Bonafide / Fully_Fake / Partial_Fake_Clean / Partial_Fake_Noisy；**30 ms 帧级标签**，含独立的 transition 帧类别；带 OpenSLR26 + MUSAN 加噪变体 | <https://zenodo.org/records/17929533> |

两点说明：

- **HQ-MPSD 是意外收获**：原来的 8 个可用集**全是英文**，HQ-MPSD 一次把语种补到 8 个，打破了"只在国内英文场景可用"的限制；它的 `transition` 帧类别对区间定位任务尤其有价值。
- **SINE 的手法无法 1:1 替代**：SINE 测的是 Voicebox 式 *seamless infilling*（整段重合成、边界无痕）。LlamaPartialSpoof 的 crossfade 和 HQ-MPSD 的 transition 帧是**近似**，不是等价。若这类攻击是核心场景，仍需找 NVIDIA 作者；否则可接受近似。

### 4.2 补 EmoFake（情绪伪造）— 需自造 ⚠️

目前**没有找到许可干净的现成情绪伪造数据集**（已知的情绪语音集如 ESD / RAVDESS / CREMA-D 多限研究用途，且它们是"真实情绪"而非"伪造情绪"）。

可行做法：用**可商用许可的情绪 TTS** 自造。

| 工具 | 许可 | 用途 |
| --- | --- | --- |
| **EmotiVoice**（网易有道） | **Apache-2.0** | 多音色 + prompt 控制的情绪 TTS，可在 LJSpeech / VCTK 的干净人声上做"同人同内容、改情绪"的重合成，正好复刻 EmoFake 的构造方式 |
| **CosyVoice2** | **Apache-2.0**（模型卡） | 支持 instruct 控制情绪/语速，可做同一说话人的情绪改写 |

自造的好处是标注天然干净（改了什么情绪你自己知道），坏处是要写生成流水线 + 人工抽检。

> 注意：CosyVoice2 模型卡虽标 Apache-2.0，README 底部有 "for academic purposes only" 的免责声明（针对示例内容）。正式商用前建议向法务确认，或改用 EmotiVoice（无此表述）。

### 4.3 补 FoR（商业 TTS 系统覆盖）— 基本堵死 ❌

这条最麻烦，原因是**结构性**的：

- 商业 TTS API（云厂商、ElevenLabs 一类）的服务条款**普遍禁止用其输出训练模型**；
- 所以 SpeechFake 里那 10 个"commercial API"生成的子集，即使数据集本身是 CC BY 4.0，**上游 ToS 仍是断的**——这和 GPL 组件问题是两层独立的雷。

因此不建议指望"找一个新的商业 TTS 数据集"来解决。现实路径是二选一：

1. **用开源 SOTA 做代理**：CosyVoice2/3、IndexTTS2、VoxCPM 等当前开源模型的自然度已接近商业 API，用它们合成的高质量样本可以有效覆盖"高自然度 TTS"这一类攻击面（注意 IndexTTS2 等需另行核对其仓库 LICENSE）；
2. **直接找 FoR 作者要授权**：FoR 覆盖 Deep Voice 3、Google Wavenet 等早期商业系统，价值在于"旧系统覆盖"，不是不可替代。

### 4.4 更新后的建议训练集

```
原 8 个：asvspoof2019  partial_spoof  vctk  ljspeech
        codecfake_ntu  partial_edit  daily_talk_edit  in_the_wild

新增 2 个：LlamaPartialSpoof   HQ-MPSD        ← 都是 CC BY 4.0

自造 2 类：情绪伪造（EmotiVoice）  高自然度 TTS（CosyVoice2）
```

合计 **10 个现成数据集 + 2 类自造数据**，覆盖：TTS、VC、编解码重合成、部分伪造定位、**无缝/交叉淡化编辑**、对话场景、野采样本、**8 语种**、情绪伪造、高自然度合成。除"商业 API 系统"这一块外，能力面基本补齐。
