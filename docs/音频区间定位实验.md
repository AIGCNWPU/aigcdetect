# 音频伪造区间定位实验记录

2026-10-23 · 对象：HoliAntiSpoof（Qwen2.5-Omni-7B + DoRA adapter）
目的：确认能否在演示页展示"可疑片段起止时间"。

## 1. 构造方式

以 CommonVoice 真人 4 秒片段为底，把 MLAAD 的 TTS 片段（16 kHz）按不同位置、不同长度拼接进去，制造"部分篡改"样本：

| 编号 | 构造 | 真实篡改区间 |
| --- | --- | --- |
| v1–v4 | 真人 + 另一说话人真人片段（0.4–0.8 s 替换） | 1.0–2.6 s 之间 |
| p1 | 真人 0–2.0 s + TTS 2.0–4.0 s | 2.0–4.0 s |
| p2 | 真人 0–1.4 + TTS 1.4–2.2 + 真人 2.2–4.0 | 1.4–2.2 s |
| p3 | 真人 0–2.6 + TTS 2.6–3.2 + 真人 3.2–4.0 | 2.6–3.2 s |
| p4 | 真人 0–1.0 + TTS 1.0–3.0 + 真人 3.0–4.0 | 1.0–3.0 s |
| h1 | TTS 0–1.8 + 真人 1.8–4.0 | 0–1.8 s |
| h2 | TTS 0–1.2 + 真人 1.2–4.0 | 0–1.2 s |
| h3 | 真人 0–2.2 + TTS 2.2–4.0 | 2.2–4.0 s |

## 2. 结果

**剪切拼接（真人换真人）一律判为真人**（v1–v4：p_fake 0.0003–0.0032），说明模型对手工剪接不敏感。

| 编号 | p_fake | 模型给出的区间 | 是否正确 |
| --- | --- | --- | --- |
| p1 | 0.014 | 判为真人 | ✗ |
| p2 | 0.994 | `"all"` | ✗（应局部） |
| p3 | 0.500 | 判为真人 | ✗ |
| p4 | 0.980 | `"all"` | ✗ |
| h1 | 1.000 | `[[1.8, 2.39]]` | ✗（指向真人段） |
| h2 | 1.000 | `[[1.2, 2.2]]` | ✗（指向真人段） |
| h3 | 0.995 | `[[0.0, 2.2]]` | ✗（指向真人段） |

**规律**：模型确实感知到拼接缝（区间端点总是落在缝上），但把**真人那一侧**标成伪造，方向相反。换成开放式提问（"哪些秒被伪造"）后仍如此，且 `spoof_method` 一律给 `cut and paste`。

## 3. 滑窗打分（替代方案）

对 h1（真实篡改 0–1.8 s）用 1 秒窗、0.5 秒步长逐窗推理：

| 窗口 | p_fake |
| --- | --- |
| 0.0–1.0 | 0.9997 |
| 0.5–1.5 | 0.9999 |
| 1.0–2.0 | 1.0000 |
| 1.5–2.5 | 1.0000 |
| 2.0–3.0 | 0.9996 |
| 2.5–3.5 | 0.0534 |
| 3.0–4.0 | 0.1824 |

2.0–3.0 s 已经是纯真人，仍给 0.9996，比真实边界过冲约 1 秒。方向是对的，精度不够。

## 4. 结论与建议

1. **不要把模型输出的 `fake_region` 直接当作"可疑片段"展示**——在本场景下它会指向错误的位置，且"全段"与"局部"无法区分。
2. 若产品需要区间能力，走**滑窗打分 + 平滑 + 阈值**自建时间轴，明确标注为"疑似区间"而非精确边界；窗口大小、平滑方式需要用标注数据调。
3. 模型擅长的是**整条判真假 + 伪造手法**，这两项在演示中表现稳定（TTS 样本 p_fake 0.98–1.00，真人样本 0.000–0.001）。
4. 若要提升区间能力，路径是：用 PartialEdit 这类**带单词级标注**的数据做微调，或在 ICL 里提供带区间的参考样本。
