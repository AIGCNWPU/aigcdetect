## 1.2 AI新闻稿与投稿内容检测

### 功能定位

面向「新闻编辑 / 内容审核」的稿件审校工具，用于判断新闻稿、投稿文章是否存在 AI 生成痕迹，并借助大模型完成文字校对。

### 场景信息

| 项 | 值 |
| --- | --- |
| 场景 ID / 编号 | `news` / `1.2` |
| 前端路由 | `#/text/news` |
| 页面文件 | `src/modules/text/pages/news.js` |
| 检测接口 | `POST /api/v1/text/news`（operationId `text_news`） |
| 正文提取接口 | `POST /api/v1/text/news/import` |

### 五大核心功能点

| # | 功能 | 说明 |
|---|------|------|
| 01 | 稿件提交 | 支持直接粘贴正文或从公开新闻链接提取正文；页面保留文档选择入口，但后端尚未解析 DOC/DOCX |
| 02 | 稿件 AI 风险检测 | 按句切分并调用中文 C-ReD 检测器，返回原文位置、AI类得分和“疑似AI/人工/无法评分”状态 |
| 03 | 三审三校（大模型 API） | 调用大模型 API 做多轮审核校对，标注表述、逻辑、用词、错别字及标点问题，并给出修改建议 |
| 04 | 修订稿重新检测 | 稿件修改后可重新提交检测；当前页面会话内记录成功版本，不提供跨进程持久化 |
| 05 | 检测报告导出 | 汇总句级AI检测和三审三校结果，导出当前结果的 JSON 报告 |

### 当前实现状态

**已实现（可运行）**

- 前端工作台 `src/modules/text/pages/news.js`：`稿件审校工作台`，三个标签页 ——「稿件提交 / 检测结果 / 历史与报告」。
  - 稿件来源包含粘贴 / 文档 / 链接入口，标题 + 正文输入带字数统计（上限 5 万字）；实际检测接口当前要求提交正文，文档解析尚未接入。
  - 检测项目复选框：**疑似AI风险** 与 **三审三校** 两类结果独立呈现。
  - 修订说明选填字段，用于标记修订版本。
  - 结果区含「结果真实性」提示：未收到检测服务回执前只显示「未检测 / 失败」，**不伪造风险分数**。
  - 历史区在当前页面会话中维护版本记录，成功收到回执后才入列；支持导出当前 JSON 报告。
- 新闻链接正文提取后端 `src/modules/text/news-import.js`：
  - 内置站点适配器：**央视网 / 中国新闻网 / 凤凰网 / 澎湃新闻**，其余站点走通用正文识别。
  - 提取标题、作者、发布时间、正文、站点名；清理脚本 / 样式 / 导航等噪声，解码 HTML 实体。
  - 识别「登录后查看、订阅付费、验证码 / 人机验证」等受限情形，给出 `partial` 提取状态与提示，绝不绕过登录付费墙。
  - 具备 SSRF 防护（仅允许公网地址，拒绝本机 / 内网地址）。
- 句级疑似AI检测：
  - 前端分句并保留字符区间，后端重新校验 `start/end/text` 与段落边界后调用 EGTE 中文 `cred` 分类器。
  - 过短单句优先与同段相邻句合并，最多两句；长句和结果列表支持滚动查看。
  - 返回随机森林的未校准 `aiScore`，界面使用“AI类得分”和“疑似AI”，不将其表述为确定概率。
  - 结果可切换“全部显示”和“仅疑似AI”。
- 三审三校：服务端通过配置的大模型接口分段审校和全文复审，只展示能精确回指原文的错别字、标点、语病、用词、局部逻辑及一致性问题；无法回指的模型结果只在后端记录计数。

## 1.3 AI网文与小说内容检测

### 功能定位

面向「网文平台 / 作品编辑」的内容治理工具，按作品、章节组织长文本，检测章节 AI 生成风险与「重复叙述、内容空泛（水稿）」线索。

### 场景信息

| 项 | 值 |
| --- | --- |
| 场景 ID / 编号 | `novel` / `1.3` |
| 前端路由 | `#/text/novel` |
| 页面文件 | `src/modules/text/pages/novel.js` |
| 检测接口 | `POST /api/v1/text/novel`（operationId `text_novel`） |
| 正文提取接口 | `POST /api/v1/text/novel/import` |

### 五大核心功能点

| # | 功能 | 说明 |
|---|------|------|
| 01 | 作品与章节管理 | 在当前页面会话内按作品整理章节，支持添加、查看、编辑和删除 |
| 02 | 章节 AI 风险检测 | 对指定单章或多章检测，逐章展示 AI 生成风险 |
| 03 | 重复与水稿检测（大模型 API） | 调用大模型 API 识别重复叙述、内容空泛等水稿线索，标出疑似段落并附判断依据 |
| 04 | 问题内容对照 | 将重复 / 水稿内容定位到具体章节与段落，可调阅原文比较 |
| 05 | 作品检测汇总 | 汇总本次已检测章节、疑似AI结果与重复水稿线索，导出 JSON 报告 |

### 当前实现状态

**已实现（可运行）**

- 前端工作台 `src/modules/text/pages/novel.js`：`作品与章节工作台`，三个标签页 ——「作品与章节 / 章节检测 / 作品报告」。
  - 章节材料表单：作品名称 + 章节名称 + 章节正文（粘贴，上限 10 万字）+ 章节文档选择入口 +「从章节网页导入」；文档选择当前只记录文件信息，DOC/DOCX解析尚未接入。
  - 章节列表支持添加、编辑、删除，可勾选单章或多章；导入时若表单已有内容会要求确认覆盖。
  - 检测项目复选框：**章节AI生成风险** 与 **重复与水稿线索**；结果按章节展示覆盖范围与可疑段落，重复 / 水稿线索定位到章节段落并附判断依据。
  - 报告页支持导出（JSON 格式），对「仅导入部分内容」有明确提示——结论不代表整章 / 整本。
- 章节网页正文提取后端 `src/modules/text/novel-import.js`（能力比新闻版更完整）：
  - 内置站点适配器：**刺猬猫 / 飞卢 / 纵横**，其余站点走通用正文识别。
  - 针对**番茄小说动态字体混淆**：检测到私用区字体字符时以 `CONTENT_OBFUSCATED` 拒绝导入，**不落乱码**。
  - 识别登录 / 付费 / 订阅 / 验证码 / 人机验证等限制，仅提取公开可读部分并给出提示。
  - 网络层防护完善：公网地址校验（IPv4 / IPv6 私网与保留段拦截，防 SSRF）、重定向上限 5 次、10s 超时、2MB 大小上限、gzip / brotli / deflate 解压、GBK / GB2312 / GB18030 / UTF-8 编码识别。
- 句级疑似AI检测：复用新闻场景的分句、后端位置校验、短句相邻合并和 EGTE `cred` 调用，结果按章节保留原文位置。
- 重复与水稿检测：
  - 服务端对选中章节进行分段窗口分析，调用配置的大模型识别重复叙述、循环对话、重复心理/景物/动作描写及明显内容空泛。
  - 完全相同的规范化段落可由本地规则直接给出重复证据；模型结果必须携带可精确回指的章节原文。
  - 一次请求包含多章时可比较请求内章节；一次只提交一章时不具备跨请求、跨历史章节记忆。
